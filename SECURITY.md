# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository's Security tab. Please do not open a public issue for an undisclosed vulnerability.

Include a description of the issue, steps to reproduce it, and any potential impact. The maintainers will review the report and follow up through GitHub.

## Supported Versions

Security fixes are generally made to the latest version of the project. Older versions may not receive security updates.
